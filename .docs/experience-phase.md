# 经验阶段（Experience Phase）规则备忘

CoC 7th 中"调查员存活封盘"后的成长流程参考。本项目对应 `scenarioEnd.kind` 为 `victory` 或 `ambiguous` 的两种存活终局，需要据此发放"生存奖励"。

> 文件来源：与用户的设计对话（2026-05-23）。规则要点对照 CoC 7e Keeper Rulebook "Experience Phase" 章节。

---

## 1. 技能成长检定（Experience Checks）

这是经验阶段的核心机制。

- **打勾时机**：游戏过程中，每当玩家**成功**使用某个技能（普通 / 困难 / 极难成功都算，**大失败 / 失败不算**），就在该技能名旁的小方框打钩。**同一个技能一场冒险只打一次钩**，多次成功不叠加。
- **成长检定**：冒险结束时，对每个被打了钩的技能各掷一次 `1d100`：
  - 若 `1d100 > 当前技能值`，**或 `1d100` 落在 96–100**（高技能保底），则该技能 **+1d10**。
  - 否则不变。
- **清钩**：检定完成后清掉所有钩，无论是否成功。

### 例外

- **克苏鲁神话（Cthulhu Mythos）** 不能通过经验成长，只能靠遭遇神话事件加点。
- **信用评级（Credit Rating）** 一般不走经验检定，由剧情 / 叙事决定。
- **闪避（Dodge）与母语** 通常通过经验成长。

## 2. 技能突破 90 的额外奖励

- 经验阶段中，**任何（克苏鲁神话以外的）技能首次达到 90%+** 时，调查员获得 **+2d6 SAN**（代表精通带来的精神满足）。
- 只有"首次跨过 90"那次给，之后再涨不重复发放。

## 3. SAN 奖励（守密人裁量）

规则书给出参考量级，由 KP 视达成程度发放：

| 事件 | SAN 奖励 |
|---|---|
| 击退 / 封印一个神话生物 | `1d6` |
| 摧毁一个邪教 / 封禁一个神话存在 | `1d10` |
| 拯救一名 NPC 性命 | `1d3` ~ `1d6` |
| 解决一桩神秘事件（非神话） | `1d4` |
| 完成模组主线 | `1d10`，视规模 |
| 阻止"重大灾厄"（仪式、入侵等） | `1d10` ~ `1d100`，KP 自定 |

> SAN 上限是 `99 - 克苏鲁神话技能值`，不能超。

## 4. 不在经验阶段做的事

容易混淆，单独列出：

- **HP / MP 不靠经验恢复**，按平时治疗规则走（HP：`1d3`/周；MP：每小时 1 点回满）。
- **POW 不靠经验涨**。标准规则下只通过特定法术 / 事件（例如施法后骰 POW 检定，成功则 +1d10）。
- **Luck（幸运）**：核心规则里**不会通过经验阶段恢复**，只能靠 KP 在剧情中明文奖励，或启用可选规则"幸运消耗后慢回"。Pulp Cthulhu 才有"幸运经验检定"。
- **属性值（STR / CON / DEX / APP / SIZ / INT / EDU）** 不通过经验阶段成长。EDU 有专门的"自我提升检定"（每隔几个月一次），但那是长期休整规则，不属于经验阶段。

---

## 5. 在本项目中的落地建议

对照 `scenarioEnd.kind`：

- **`victory`**：完整经验阶段 — 技能勾全部检定 + 突破 90 奖励 + 较高的 SAN 奖励（例如 `1d10` + 模组特定加成）。
- **`ambiguous`**：缩水版 — 技能勾照常检定（中性奖励，付出过努力就该回报），但 SAN 奖励减半或归零，甚至倒扣，代表"赢得不光彩"。

> `dying` 是单回合垂死窗口（中间态，不封盘），`dead` / `insane` 不进入经验阶段。
