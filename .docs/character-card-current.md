## 四、技能（规则描述 / 计划改造）

> **现状**：当前自定义角色卡只有 9 项固定技能（侦查 / 聆听 / 图书馆使用 / 神秘学 / 心理学 / 手枪 / 潜行 / 说服 / 格斗(斗殴)），可 ±5 / 手填，范围 1–99。**已不符合 CoC 7e 规则**，计划按下述方式重做。

### 4.1 可选技能筛选规则

按 CoC 7e 规则，调查员的可选技能由两条数据源筛选得出：

1. **年代筛选**：根据 `年代背景`（`selectedEra = "1920s"` 或 `"modern"`）从 `.docs/skill-1920s.md` 或 `.docs/skill-modern.md` 取对应时代的标准技能表（含通用技能 + 多分支技能：Art/Craft、Science、Firearms、Fighting、Survival、Language(Other)、Drive、Pilot 等）。
2. **职业筛选**：根据玩家在`角色职业`下拉中选定的职业，从 `.docs/occupation-list.md` 取该职业的"核心职业技能"列表（占 6–8 项 + *自定 N* 槽位）。

> 说明：**信用评级、母语、闪避**已移出职业模板与技能表，不再作为可选技能项（详见基本信息行的备注与 `.docs/skill-*.md` 的备注段）。
> **克苏鲁神话**默认 0，不在可选范围；只能通过 KP 在游戏中下发 `sanitySkillGain` 加点。

### 4.2 选择上限

调查员**最多**只能选择：

- **8 项职业技能**（必须从 4.1 第 2 步中"该职业的核心职业技能"+ "*自定 N*" 中挑选；其中"*自定 N*"槽允许玩家从 4.1 第 1 步的全标准技能表中自由挑选 N 项填入）。
- **4 项兴趣技能**（可从 4.1 第 1 步的全标准技能表中任意挑选，不受职业限制）。

合计上限：**8 职业 + 4 兴趣 = 12 项**。未被选中的标准技能保持其"基础值"（详见 `.docs/skill-1920s.md` / `.docs/skill-modern.md`），不出现在角色卡的"已掌握技能"列表中，但仍可在游戏中以基础值进行检定。

### 4.3 点数池与分配规则

按 CoC 7e 规则：

- **职业技能点池** = 该职业模板规定的属性公式（常见为 `EDU × 2 ~ EDU × 4`，各职业不同；具体公式后续从 7e 职业模板表补全到 `.docs/occupation-list.md`，本项目第一阶段统一使用 `EDU × 4` 作为兜底默认值）。
- **兴趣技能点池** = `INT × 2`。
- 单项技能上限：**99**；下限不低于该技能的"基础值"（即不能往下扣）。
- 职业点只能投到"已选 8 项职业技能"上，**不可**投到兴趣技能；兴趣点只能投到"已选 4 项兴趣技能"上，**不可**反向补职业技能。两个点池**互不通用**。
- 提交时自动写入 `skills["克苏鲁神话"] = 0`，不占用任何点池。

### 4.4 随机生成

技能的随机生成功能见 **五、辅助操作**「随机宿命技能分配」。

## 五、辅助操作

| 功能 | 说明 | 触发按钮 |
|---|---|---|
| 随机宿命投骰 | 八维各 `3D6 × 5`（或 `(2D6+6) × 5`），全量重置 | 「随机宿命投骰 (3D6 Roll)」 |
| **随机宿命技能分配（待实现）** | 按 CoC 7e 规则一键生成合法的技能选择 + 点数分配。流程：① 读取当前 `年代背景` + `角色职业`，按 4.1 筛选"职业技能候选集"与"全标准技能集"；② 从候选集随机抽 **8 项**作为职业技能，"*自定 N*"槽位从全标准技能集随机抽 N 项填入；③ 从全标准技能集（去掉已选 8 项后）随机抽 **4 项**作为兴趣技能；④ 按 4.3 点数池规则在 8 + 4 项上加权随机分配（建议偏正态分布，避免"全堆 1 项 / 全平均"两个极端），每项 = 基础值 + 投入点数，不超过 99；⑤ 输出后玩家仍可在 UI 微调，受 4.2 上限与 4.3 点池规则约束。 | 「随机宿命技能分配」 |
| 智能根据概述生成数值 | 调 LLM，按 `customOverview` 分配属性 + 技能 | 「根据概述生成数值并分配」 |
| 导入 PNG 角色卡 | 从带 metadata 的 PNG 还原属性、技能、头像 | 「上传角色卡图片」 |
| 上传肖像 | 仅头像，会话内有效 | 「上传肖像图片 (JPG/PNG)」 |
