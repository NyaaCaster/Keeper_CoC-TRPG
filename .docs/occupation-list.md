# CoC 7e 标准职业列表（1920s / Modern）

按 CoC 7th Edition Investigator Handbook 整理。每条职业的"核心技能"为该职业默认的 8 项之一，其中若干项允许玩家在指定范围内自定（标 *自定*）。

> 用途：用作"自主缔结专属卡片"分页中"角色职业"下拉列表的备选数据源。两张表分别对应 `selectedEra = "1920s"` 与 `selectedEra = "modern"`。
> 时间：2026-05-23

## 备注

- "*自定 N*" 表示该职业允许玩家从 7e 标准技能表中自由挑 N 项作为职业技能。
- **信用评级、母语、闪避不在职业技能列表中**：这三项 7e 名义上的"技能"在本项目里被移到基本信息层（信用评级 / 母语）或派生战斗值（闪避），不再作为职业技能模板的一部分；详见 `.docs/character-card-current.md` 一、基本信息 + `.docs/skill-1920s.md` / `.docs/skill-modern.md` 的备注段。
- 表格仅列出职业技能（占 6–8 项），玩家在创建时还可以从 INT × 2 的兴趣点池里自由选技能。
- 1920s 与 现代 共有的职业（如医师、律师、警探、艺术家等）在两张表里各列一份，以便下拉只用一张表即可——**不要尝试做"共有职业去重"**，时代风味在两张表里可能略有差异。
- 后续如要扩展型月 / SCP 世界观特化职业（魔术师、SCP 特工、教会代行者等），建议另开一张表并标注"非 7e 原生"。
