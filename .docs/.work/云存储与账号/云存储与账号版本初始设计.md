# Keeper_CoC-TRPG 改造
## 添加账号系统
- 增加一个 Keeper_CoC-TRPG 的用户系统 `调查员账户`
- 首页在现在的 `踏入全新的漩涡`、`继续未完的调查`、`虚空连接的设置` 这组按钮，定位登录后才出现的游戏开始选单
- 在游戏开始选单前加入账号登录功能 `调查员登录` ，要求输入 `账号或邮箱`、`密码` ，以及登录按钮、`没有账号？去注册`的按钮，点击后开打新网页跳转至 `http://h.nyaa.host:5110/?view=register`
- 本地储存用户登录状态，在用户退出登录前保持登录。

## 添加云端储存系统
- 将 Keeper_CoC-TRPG 的本地储存从 localStorage 改为 idb
- 大文件储存位置 `E:\DockerRes\Keeper_CoC-TRPG\` ，在 `.env` 配置，`.env.example` 中则配置为 `.`
- 建立 Keeper_CoC-TRPG 的服务器储存后端，采用 NyaaChat 的后端数据库和储存方案（但不需要 NyaaChat 角色共享库的功能，只用于储存用户设置和聊天记录）
- 按照 NyaaChat 上传下载设置的功能及交互设计，给 Keeper_CoC-TRPG `虚空连接的设置` 底部 导入设置/导出设置 两个按钮前，再加入 下载设置/上传设置 两个按钮，让用户可以跨设别使用云端服务器储存同步设置
- 按照 NyaaChat 上传下载对话记录的功能及交互设计，给 Keeper_CoC-TRPG 的 调查记录档案 界面增加 下载记录/上传记录 两个按钮，让用户可以跨设别使用云端服务器储存同步调查记录
- 按照 NyaaChat 对话记录占用储存计量条 的设计，给 Keeper_CoC-TRPG 的 调查记录档案 界面增加 调查记录占用储存 计量条，注意使用 Keeper_CoC-TRPG 的UI控件、配色方案。Keeper_CoC-TRPG 的调查记录本地储存上限限制为100MB，做好类似 NyaaChat 的储存边界限制方案。
- 在 Keeper_CoC-TRPG 游戏主界面顶部菜单栏的 `调查员面板` 按钮左侧加上图标按钮 `调查员账户`，icon为 id-card ，点击后打开以 NyaaChat 的 共享账号 界面为基础的二级界面，注意保持 Keeper_CoC-TRPG 的UI控件、配色方案，显示内容为：
  - 账号
  - 用户名（初始用户名与账号相同，可修改，仅作显示用，不涉及鉴权）
  - 注册时间
  - 账号管理 按钮（点击后开新页面跳转至 http://h.nyaa.host:5110/ ）
  - 退出登录 按钮（退出登录会返回至开始页面并退出登录页面，用户点击本按钮时需要和游戏内设置界面中`退出调查`按钮一样，弹出`退出调查`的二次确认弹窗）
