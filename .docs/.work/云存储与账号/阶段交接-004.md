## 设计决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 账户状态水合时机 | App.tsx mount 时 useEffect 异步读取 IDB | 无需改动 main.tsx bootstrap 顺序；与 saveManager hydrate 模式一致 |
| 退出登录行为 | 同时退出游戏（返回 start 模式） | 安全设计：不保留无登录态的游戏会话 |
| 登录表单位置 | StartScreen main 视图内，三个按钮上方 | 登录前不显示游戏入口，登录后自然过渡 |
| ConfirmModal 变体 | danger（红色标题+红色按钮）/ default（绿色标题+绿色按钮） | 与原有退出确认样式兼容，同时支持未来其他场景 |
| rename 交互 | inline 编辑（Pencil→input+Check/X） | 不弹二级 modal，简洁且符合账户面板的信息密度 |
