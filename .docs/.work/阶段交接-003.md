## 设计决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| HMAC-XOR 实现 | Node crypto（非 @noble/hashes） | @noble/hashes 在 TS bundler 模式下子路径类型解析有问题；Node crypto 零配置可用，与 NyaaChat shared-server 一致 |
| 数据库路径 | 环境变量 `KEEPER_DB_PATH`，默认 `./data/db/keeper.db` | 容器内 `/data/db/keeper.db`，由 docker-compose bind mount 提供持久化 |
| 表设计 | 3 张表，无 password 列 | 新项目直接弃存密码，nyaa_uid 唯一索引确保跨平台账号关联 |
| 路由模式 | Express Router 挂 `/api/account/*` | 同进程嵌入，无需 nginx 反代；Router 级 requireAuth 中间件 |
| JIT 建号 | 首登自动建本地行（按 nyaa_uid），冲突时拼接 `_nyaa<uid>` | 与 NyaaChat 完全一致 |
| Fail-closed | 变量缺失→503，网络失败→503，绝不回退 | 安全红线 |
