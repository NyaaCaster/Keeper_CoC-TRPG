## 备注

- "多分支"技能（Art/Craft、Science、Firearms、Fighting、Survival、Language(Other)、Drive、Pilot 等）每个分支独立成长、独立打钩。
- 闪避 / 母语 / 信用评级 这三项 7e 名义上的"技能"在本项目里**不在技能表中**：闪避作为派生战斗值（基础 = `floor(DEX/2)`）由 `cocRules.ts` 现算，不进角色卡；母语与信用评级作为基本信息字段（详见 `.docs/character-card-current.md` 一、基本信息）。
- 克苏鲁神话**不通过经验阶段成长**，详见 `.docs/experience-phase.md`。
- 与 1920s 表相比，现代版本新增：计算机使用、电子学、计算机科学、法医学、遗传学、链锯（格斗）、卡车 / 船 / 飞机 / 直升机（驾驶）；省略了驾驶（马车）、精神分析的"早期弗洛伊德学派"风味注解。
