### CoC 检定 · `roll_coc`

克苏鲁的呼唤第七版桌游用，1d100 比技能值，**点数越低越好**。支持奖励骰 / 惩罚骰。

**你可以这么说**：
- "做一次侦查检定，技能 65"
- "图书馆使用 70，时间充裕给我一个奖励骰"
- "潜行 45，背景嘈杂给一个惩罚骰"

**会得到什么**：

```
CoC 技能检定（技能值 65，奖励骰 ×1）
  十位骰：8, 5, 2*  → 取 2
  个位骰：8
  最终：28
  判定：困难成功（≤32）
  阈值参考：普通 ≤65 / 困难 ≤32 / 极难 ≤13 / 大成功 =1 / 大失败 =100
```

#### 给 DnD / CoC 检定的 World Info 推荐

建议在世界书（WorldInfo）中插入以下两条，让投骰行为在 RP 中表现更顺滑。配置方法与第三部分的"时间天气感官化规则"一致：新建 entry → 勾 Constant → Order 100 → 把下面 Content 整段粘贴进去。两条建议合并到同一个 entry，也可以拆成两个分别管理。

**第一条：明骰 vs 暗骰**

```
#### 明骰 vs 暗骰

- **明骰**：用户主动声明的检定（"我侦查一下"）、攻击 / 豁免、自身行动检定 → 将工具返回的骰点和判定结果都告诉用户。
- **暗骰**：GM 主动触发的检定（隐藏的感知 / 洞悉 / SAN 检定 / 对方欺瞒判定 / 随机遭遇等"用户提前知道结果就破坏沉浸感"的检定）→ 不公开具体骰点，用【暗骰】或类似标记引出，只告知判定结果或直接叙事化呈现。
- 拿不准就走明骰；只有"用户提前知结果会破坏体验"的场景才暗骰。
```

**第二条：检定结果展示的格式参考**

```
#### 检定结果展示的格式参考

例如数据结果为（技能 60、奖励骰 1 个、最终 04），展示方式应该为：

> **🎲 04**
> 十位骰 [3, 0] 取 0，个位骰 4。
> **✨ 极难成功**

阈值：≤12 极难 / ≤30 困难 / ≤60 普通。
```
